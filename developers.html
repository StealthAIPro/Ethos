Start a physical capture card before running Python or native CV. Capture and preview have independent frame rates. The script receives the latest available frame when it is ready, so a slow script can skip frames while the preview continues.

Python SDK

Use a compatible 64-bit CPython 3.10–3.13 installation. In the Python tab, import your script, open Dependencies to install packages in its environment, and start capture. Then select Start script and review the launch. Ethos adds visioncore to the script environment.

from visioncore import VisionCore

app = VisionCore()

@app.on_start
def setup():
    app.log(f"Running in profile {app.session['profile']}")

@app.on_frame
def process(frame):
    app.rect(16, 16, frame.width - 32, frame.height - 32)
    app.text(24, 34, f"{frame.width} × {frame.height}")

@app.on_shutdown
def stop():
    app.log("Stopped")

app.run()

Lifecycle, session, and settings

  • on_start(fn), on_frame(fn), and on_shutdown(fn) register callbacks. Register one callback of each kind, then call run() once. The shutdown callback runs on an orderly stop.
  • app.settings reads the profile’s JSON settings for the current run. app.session provides sdkRevision, appVersion, runtime, profile, controllerBackend, captureSource, and captureFormat.
  • app.log(message) writes to the output console. The host also captures script output and Python tracebacks.
  • app.discord and app.identity are available for resources configured with the corresponding access policy. See the fields and verification flow.

Native C++ SDK

Build a Windows x64 DLL with the Visual Studio C++ toolchain. Define VC_BUILD_PLUGIN, include visioncore_plugin.h, and export vc_get_plugin(uint32_t host_abi). The function returns your static VcPlugin table for ABI 1. Set its struct_size to sizeof(VcPlugin).

cmake -S sdk/native/examples -B example-build -G "Visual Studio 17 2022" -A x64
cmake --build example-build --config Release

Import VisionCoreFrameOutline.dll from the example build’s Release folder in C++. Start capture, then choose Start plugin.

  • initialize(host, settings_json, instance) receives the host table, UTF-8 JSON, and a place to store your instance. Return 0 to accept. Clean up partially initialized state before returning an error.
  • on_frame(instance, frame) receives read-only RGBA8 and the physical controller state. Respect row stride and pointer lifetime. Call host->draw and host->set_controller synchronously here. Return 0 to publish the frame’s output.
  • shutdown(instance) releases resources on orderly stop. Keep C++ exceptions and memory ownership on your side of the DLL boundary.
  • VcControllerOutput uses button_mask, axis_mask, and trigger_mask to select overridden values. The public header lists control enums and overlay shape layouts.
  • Check VC_HOST_BASE_SIZE and VC_HOST_HAS(host, field) when using optional revision 2 callbacks frame_info and session_json. Use frame data in on_frame. Session JSON describes the launch.
  • VC_PLUGIN_CONTROLLER_ONLY tells the host pixel access can be skipped. In the standard import runner this flag can still run on capture timing. The bundled NoMeter26 resource has dedicated controller-only routing.

Standalone processes

Import a .vcplugin.json file beside a Windows x64 executable. Example manifest:

{"name":"Frame Outline","kind":"process","abi":1,"entry":"FrameOutline.exe"}

Ethos starts the executable with --visioncore-native-v1 <mapping-name> <capacity-bytes>. The transport uses UTF-8 JSON lines. Reserve stdout for protocol messages, flush each line, and log to stderr or send a log message.

DirectionTypeFields
Host to plugininitializeabi: 1, settings, and optional session.
Plugin to hostreadyabi: 1 and a three-part version.
Host to pluginframewidth, height, stride, controller, and optional frameInfo with sequence, receivedNs, and skipped.
Plugin to hostdoneOne response per frame. Optional overlays and partial controller output.
Plugin to hostlog, errormessage. Exit nonzero after a fatal error.
Host to pluginstopFinish the current frame and exit. Treat stdin closure as shutdown.

Open Windows shared memory with OpenFileMappingW(FILE_MAP_READ, …). Validate stride against width and mapping capacity before accessing RGBA pixels. Read the frame only while it is pending.

Each overlay uses kind, x, y, a, b, color, weight, and optional text. For a rectangle, a and b are width and height. For a line they are the end point, and for a circle a is the radius.

{"type":"done","overlays":[{"kind":"rect","x":16,"y":16,"a":100,"b":60,"color":"#c4a3ff","weight":2}]}

Write an OFS script

Save a UTF-8 text file with the .ofs extension. Use the OFS tab to import it, connect the selected controller bridge, then select Start script. OFS uses controller updates and does not require a capture feed.

-- ofs {"name":"Stick deadzone","author":"Example","version":"1.0.0","requires_api":1,"permissions":["controller.read","controller.write"]}
function on_tick(dt_ms)
    if math.abs(offset.get("RX")) < 10 then
        offset.set("RX", 0)
    else
        offset.release("RX")
    end
end

Download the OFS example

Put optional -- ofs {…} metadata on the first line. Available fields are name, author, version, description, requires_api, and permissions. The header defaults to controller.read. Request controller.write to override controls. The current API version is 1 and the source limit is 256 KiB.

Callback or APIBehavior
on_init()Runs once after the script loads.
on_tick(dt_ms)Runs on controller input updates. Receives elapsed milliseconds since the prior tick.
on_event(control, value, previous)Receives input changes using canonical control names.
on_unload()Cleanup callback. New writes and timers are unavailable here.
offset.get(name)Reads physical input. Sticks are −100…100 with positive Y up. Triggers are 0…100. Buttons read as 0 or 100.
offset.set(name, value) · offset.release(name)Set or clear a single override. Release hands that control back to physical input.
offset.hold(name, value, ms)Sets the control temporarily and returns a timer ID.
offset.after(ms, fn) · offset.cancel(id)Schedule a callback or cancel a timer. Delays are 0…60,000 ms. The runtime allows 64 timers.
offset.now() · offset.log(text) · offset.api_versionElapsed milliseconds since load, workspace logging, and API version.

Control names are case-sensitive. Axes are LX, LY, RX, RY. Triggers are LT and RT. Buttons include A B X Y LB RB Back Start LS RS Guide Touchpad Capture PaddleR PaddleL PaddleR2 PaddleL2 Misc1 Up Down Left Right. PlayStation aliases include Cross Circle Square Triangle L1 R1 L2 R2 L3 R3 PS Options.

Use the available Lua base, math, string, and table functions. File loading, external processes, network libraries, and compiled bytecode are unavailable. Keep callbacks short so they stay within the execution budget.

Write a GPC3 script for Ethos

Save the source as .gpc3 and import it in the OFS tab. The translator accepts a single main { … }, comments, set_val, get_actual, get_val, and braced if/else with simple numeric comparisons.

main {
    if (get_actual(STICK_1_X) > 80) {
        set_val(STICK_1_X, 80);
    } else {
        if (get_actual(STICK_1_X) < -80) {
            set_val(STICK_1_X, -80);
        }
    }
}

Download the GPC3 example

  • get_actual(control) reads physical input. get_val(control) reads the value already assigned this tick or the physical value if no assignment exists.
  • set_val(control, expression) accepts a numeric literal or one supported read. Comparators are == != >= <= > <. Semicolons terminate set calls.
  • STICK_1_X/Y maps to right stick and STICK_2_X/Y to left stick. GPC3 Y uses its original sign convention. BUTTON_1 through BUTTON_18 map, in order, to Guide, Back, Start, RB, RT, RS, LB, LT, LS, Up, Down, Left, Right, Y, B, A, X, and Capture.
  • Assignments reset between ticks. Unsupported syntax such as combos, arithmetic expressions, GCV packet helpers, input translators, and compiled bytecode produces an output-console error.

Controller input and output

Profile 1 uses Remote Play, profile 2 uses Titan Two, and profile 3 uses Makcu. Use the right-hand Controller selector for the physical input device. The selected bridge owns output. Video scripts continue to use the physical capture card for frames.

Python and native processes expose connected, buttons, axes, and triggers. Python buttons take booleans. Axes lx ly rx ry use −1…1 with positive Y up, and lt rt use 0…1. Common buttons are a b x y lb rb back start ls rs guide up down left right. Availability depends on the bridge.

if app.controller.get("connected") and app.controller["buttons"].get("ls"):
    app.set_controller_output(axes={"lx": 0.0})

Apply partial overrides only for the controls your script handles. Physical input passes through for other controls. CV overrides expire on stop, disconnect, or after frames stop arriving. OFS can explicitly release controls between ticks.

Package a resource

Open a .vcresource.json in Resources → Open manifest. Ethos checks the metadata and file hashes before copying the resource. Start the resource separately after installation.

{
  "schema": 1,
  "platform": "windows-x64",
  "id": "studio.frame-inspector",
  "name": "Frame Inspector",
  "developer": "Your studio",
  "version": "1.0.0",
  "type": "python",
  "entry": "frame_inspector.py",
  "files": { "frame_inspector.py": "REPLACE_WITH_64_HEX_SHA256" }
}
(Get-FileHash -Algorithm SHA256 -LiteralPath '.\frame_inspector.py').Hash.ToLowerInvariant()

Download the ready-to-import example manifest. Keep it beside the matching frame inspector script.

Set type to python, native, controller, or weights. Native manifests require abi: 1 and a DLL or standalone-process manifest entry. Controller entries use .ofs or .gpc3. Weight entries use .onnx or .oxm for Trace. List every package file under files with its SHA-256, including the entry and any optional thumbnail in PNG or JPG. Use relative paths with forward slashes.

Optional fields include description, dependencies, permissions, and preview. Dependencies and permissions describe expectations on the resource card. Use the Python environment controls to install Python dependencies. preview: false hides the workspace preview for a script that requests it.

Discord and device binding

Require a server membership or role

"discord": { "guildId": "222", "roles": ["333", "444"], "requireAll": false }

Replace the example IDs with your own Discord IDs as strings. Omit roles for membership alone. Roles match any listed role by default, or every role with requireAll: true. Optional userId pins access to one account. Resource Discord policies apply to Python and native packages.

Ethos reuses the sign-in from Settings → Account. Python reads app.discord, and native packages receive settings under discordAccess. Verified fields are verified, userId, guildId, and matching roles.

Bind a product license to an account and device

Register a product and its access policy with the Ethos service operator. Set developerProduct to the same identifier as the resource id. Python receives app.identity. DLLs read developerAccess in settings_json, and standalone processes receive it in initialize.settings.

The result contains productId, discordId, deviceId, expiresAt in Unix milliseconds, and an assertion. Send the assertion to your backend over HTTPS. Verify ES256 using the operator’s pinned key and expected kid, iss, aud, and exp. Compare signed sub and deviceId with license records. Consume jti once when exchanging it for a longer session. The device ID represents a product-scoped Windows key.

Troubleshooting

  • Start is disabled. For CV, start a physical capture card and wait for frames. For OFS or a controller-only resource, connect the selected bridge.
  • Missing Python modules. Select the environment for the script and install its requirements there. The interpreter shown in the workspace drives that environment.
  • Capturing at high FPS. The card, driver, chosen resolution, and pixel format determine available rates. Processing FPS reflects completed callbacks, and display FPS depends on preview presentation.
  • An override has no effect. Check bridge connection, physical controller selection, control name, value range, and where your script writes output. Read the output console with Ctrl+J.
  • Resource fails inspection. Check entry type, manifest version, relative paths, and SHA-256 values. Reopen the manifest after changing any files.
